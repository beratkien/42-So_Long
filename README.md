# 42-So_Long
Basit ama eğlenceli bir 2D oyun projesi. Amaç, karakteri harita üzerinde yönlendirerek tüm coin’leri toplamak ve çıkışa ulaşmak. Harita dosyaları .ber formatında ve program başlatılırken dışarıdan veriliyor.

MiniLibX grafik kütüphanesi kullanılarak geliştirilen proje, temel oyun mekaniği, harita kontrolü ve kullanıcı etkileşimini bir araya getiriyor. 42 okulu kapsamında, grafik programlamaya giriş için hazırlanmış bir C projesidir.
